# Shopware 5

### Manual Installation

Follow these steps to add custom JavaScript to your Shopware 5.7 shop:

1. Log in to your Shopware Admin Panel

2. Navigate to **Configuration** > **Theme Manager**

3. Find your active theme and click on the **gear icon** to edit it

4. In the theme editor, look for the **Other** or **Advanced** tab (depending on your specific theme)

5. Find the **External JavaScript** section or field

6. Make sure to include the proper `<script>` tags:

<img src="/images/integrations/shopware-5/external-javascript.png" />

```html filename="index.html" copy
<!-- Load the mySHOEFITTER Script -->
<script src="https://js.myshoefitter.com/v1/script.js"></script>

<!-- Initialize mySHOEFITTER -->
<script type="application/javascript">
  myshoefitter.init({
    shopSystem: 'shopware'
  });
</script>
```

7. Click **Save** to apply your changes

8. Click "Recompile Theme" in the popup

9. Visit your shop's frontend and verify that your JavaScript is working as expected

### Alternative Installation (using a plugin)

1. Log in to your Shopware admin panel

2. Go to Settings -> Plugin Manager

3. Search for "Custom HTML"

<img src="/images/integrations/shopware-5/install-custom-html.png" />

4. Purchase the Plugin an locate your purchased/downloaded plugin in the list

5. After successful installation, click the switch button to activate the plugin

6. Go to Extensions -> Custom HTML

<img src="/images/integrations/shopware-5/custom-html-plugin.png" />

7. Add the code inside the textbox that says "...before the footer"

```html filename="index.html" copy
<!-- Load the mySHOEFITTER Script -->
<script src="https://js.myshoefitter.com/v1/script.js"></script>

<!-- Initialize mySHOEFITTER -->
<script type="application/javascript">
  myshoefitter.init({
    shopSystem: 'shopware'
  });
</script>
```

8. Click the "Save and Compile"-Button

Visit your shop's frontend and verify that your JavaScript is working as expected
